Typical owner's manual guidance: if the fuel filler cap is loose or missing after refuelling, the check engine light can come on because the fuel system is not sealed (an evaporative leak, code P0457). Tighten the cap until it clicks; the light goes off by itself after several drives. If it stays on, have the car checked.
